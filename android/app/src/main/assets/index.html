IRA ZTE Live Signal Charts

Dashboard telemetry real-time untuk router ZTE MC8501 5G, termasuk grafik kualitas sinyal, status tower/internet, riwayat koneksi, dan ping latency.

Updater APK menggunakan GitHub Releases. Stable dan Beta hanya mengunduh aset APK yang cocok.
